# v0.1 实现协议与已知限制

实现版本 `worldmind-0.1.0/river-1`。本轮从规划重新编码。
本文件记录 07 计划如何落地，以及哪些长期协议没有进入本版本。

## 世界、动作与角色

七区域、八条双向道路，静态地图和地点用途是公共信息。动态通行状态和库存只在当前区域直接观察，或来自初始带时效的配送简报。初始简报是独立常量，不由世界真相复制；隐藏干预不会改变它。

快递员为唯一规划角色；医生固定在诊所接收交付；商人固定在仓库，默认等待，可用 `Config(merchant_takes_at=2)` 在指定 tick 按规则取一份药材。患者住处是交付目标。商人不调用模型，也不自主规划。三预设目标为患者药物、诊所药材、诊所药物；每个目标完成一次即满足。

| 动作 | 条件 | 提交效果 / 取消 |
|---|---|---|
| move | 邻接道路在执行时真实可通行 | 一个离散步后到相邻区域，不瞬移 |
| inspect | 目标是当前区域 | 刷新当前库存及邻接道路的直接观察；规划验证止于观察屏障 |
| take | 当前区域有药材、自身药材少于 2 | 原子减库存、增自持药材 |
| craft | 工坊有一份自持药材、药物少于 2 | 第一 tick 消耗药材，下一 tick 产药；中断无退款 |
| deliver | 在当前目标接收地点，持有所需物品 | 原子消耗/转移并登记该目标交付 |
| wait | self 或当前地点 | 一 tick，无资源变化；搜索器不生成无收益等待环 |

单步先推进 tick、处理固定背景取材、完成上一步制作，再刷新观察、规划和执行一个动作。
制作完成的 tick 不再开始另一动作。除 craft 外的动作在一个离散步内原子提交；这比长期文档中通用 start/continuous/finish/租约系统更窄，原因是保持首版六动作语义可检验。
没有跨 NPC 工作单、通用 escrow、任意长动作、任意资源或通用游戏引擎。

## 信息边界与规划

规划器只接收不可变 `Context(State, goal, evidence expiry, actor versions)`；该 State 由自身确认状态和角色证据构造。它不包含真实远端库存、商人状态、全局日志序号、世界哈希或调试权限。模型只收到角色上下文、公共地图和静态动作语义。页面世界面板为特权调试；切换角色地图会单独请求 `/actor` 受限投影。

过期证据变成 None/未知，不自动反转真假。没有概率信念、传闻合并、冲突多来源推理；证据历史可通过输入重执行获得，不存完整通用信念数据库。隐藏变更命令立即改变世界，角色在下一次合法观察阶段才能得知。

Full/Local 共享 BFS、状态编码、30 动作深度边界、未知处理和 `transition` 校验器。
预算单位明确为“一个节点展开”或“一次计划动作校验”；两类都占同一个每次/累计预算。
Local 尝试替换未执行计划的连续前窗口 `[0,r)`，最多三个右边界，保留后缀；每次候选都重检完整剩余序列。局部预算最多约占决策余额四分之一，失败使用同一余额回退 Full。
已执行动作不在待修复窗口中。它是首版有界窗口算法，没有声称最小依赖切片、最优修复或完整 DAG 研究实现。

未知事实需要先到达观察点，返回 inspect 结尾的可执行前缀；不虚构 inspect 结果再认证后续计划。
无搜索结果返回 `unknown/no_plan_in_current_belief`，预算耗尽返回 `budget_exhausted`；没有使用评测器全知状态提前报告永久无解。

界面 CPU 数值只测规划与序列验证过程，不含观察合并、HTTP、渲染、模型网络等待，不能直接代替长期研究协议的总决策成本指标。所有正式研究统计、独立场景、性能规模标定均未完成。

## 并发、取消与会话

FastAPI 单进程，每会话 asyncio lock 单写者；有界计算在工作线程执行，取消请求也等待线程完成才释放写锁。后台运行每 250 ms 尝试推进一个模拟步，暂停在已提交边界生效。四个计算槽限制并行核心任务。

`/commands` 必须提供会话 token、command_id、expected_revision。同 ID 同内容返回不可变原响应，同 ID 异内容拒绝；两个相同 revision 的并发写入只允许一个成功。revision 是调试会话控制字段，不进角色上下文。控制操作（run/pause/reset）不是世界动作；界面不自动重试它们。

模型请求处于 barrier，暂停模拟等待回复；干预、目标修改、取消、重置仍可进行。会话 epoch 与角色上下文摘要共同防止旧回复覆盖。隐藏世界变化本身不让提议过期，避免该行为成为信息旁路；最终动作仍按真相复核。取消不能保证供应商停止计费，因此请求额度不退还。

会话 token 为不可预测的能力凭证，不在 URL 中；这是演示服务的隔离机制，不是完整用户账号体系。
模型入口还需独立服务端口令。设置 Host 与 Origin 限制；无任意浏览器端 URL/密钥配置。
当前没有完善的多租户身份管理、分布式限流、TLS 终端或生产可用性保证。

## 回放与持久化

导出含版本、初始配置、每条输入、每步逻辑状态哈希和事件哈希。导入先全部重执行验证，成功后才替换会话；回放每步仍重新校验。CPU 时间等非确定字段不入哈希。模型通过校验后的动作提议作为结构化输入记录；重放不调用模型。

模型审计独立持久保存，网络错误、取消与用量不作为世界剧情真相。导出不含 API Key、认证头、任意原始响应或隐藏思考。回放能重建世界和动作/规划轨迹，**不重现真实网络时延、模型等待动画或供应商计费过程**。

哈希用于发现损坏和不一致，不是数字签名；能重写整个记录并重算哈希的操作者可构造另一条合法轨迹。只支持同版本；没有自动迁移旧版本、跨版本证据或云端存档。模拟会话存内存，重启会丢失；SQLite 只保存模型请求额度、校验缓存和脱敏审计。

## 交付边界

已提供本地启动、源码、配置示例、测试、可导入失败记录和 CI 工作流。没有部署公开演示，没有真实供应商调用、真实成本、长期负载、10–20 NPC 或 Windows 本机实测。Windows/Linux CI 是否通过需另看 GitHub Checks。

界面为代码仓库开发演示，不含编辑器、3D、美术资源、开放自然语言目标、多模型自动 Agent、训练或商业游戏适配。研究新颖性与收益仍待独立文献核验和实验。
