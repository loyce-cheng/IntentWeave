## 重点覆盖

- 三目标、六动作、正常任务；双世界隐藏道路/材料直到合法接触前保持相同角色输入。
- 过期证据变未知；远程取材、瞬移、无效实体、额外字段、重复 JSON 键和非有限数被拒绝。
- 整个剩余计划复核；Local/回退共享额度；缺材、无路、预算耗尽有限退出。
- 制作跨 tick 消耗/产出；中断不退款；背景角色资源竞争不重复消费。
- 会话能力校验、隔离、相同 revision 并发写入、命令幂等与冲突、暂停/运行/重置。
- 取消工作线程时保持写锁直到完成；模型 barrier、取消、超时、并发限额和五次会话上限实现。
- 换目标/重置/取消后的迟到响应丢弃；隐藏变更本身不让模型提议过期。
- 每个已注册供应商配置的请求、鉴权、解析、HTTP 错误、语义拒绝、缺失用量、缓存、重启额度和审计。
- 原生协议不同用量字段，推理/缓存 token 数值保留；缺失用量与费用不记成零。
- 超大响应、重定向、网络异常、拒绝/截断/工具调用拒绝；无自动付费重试或跨供应商回退。
- 缓存重新校验、模型/配置改变不误命中；SQLite 并发占额、在途重启保守记账。
- 导出/导入/逐步回放；状态与事件损坏定位；失败导入不覆盖当前模拟；日志无供应商密钥和原始错误。
- 桌面与 390px 移动视口；浏览器完成流程、对照、失败路径、损坏导入和模型默认关闭。

## 开发中出现的问题与处理

- 初次隐藏材料测试在角色已经走到药圃后仍要求观察相同。按感知语义拆为“接触前相同”和“接触后必须不同”，没有取消隔离检查。
- 当前供应商文档复核发现 MiMo 使用 `max_completion_tokens` 的新示例；修正参数及专用 api-key 鉴权，并加入独立于配置表的字段断言。没有声称模拟能验证真实模型兼容性。
- 一次前端格式检查未通过；按项目安装的 Prettier 重排后重新执行检查、构建和浏览器测试。
- 受限沙箱中线程事件循环/本机网络导致 TestClient 等待；开放命令所需网络权限后完整测试通过。
- npm 默认缓存目录不可写，改用 `/tmp/worldmind-npm-cache` 完成安装。
- Playwright 浏览器 CDN 返回 Domain forbidden。未绕过网络策略，改用环境已安装的系统 Chromium，6 项测试实际执行。
- 手动 `--no-build-isolation` 安装因缺少构建后端失败，标准 `pip install -e '.[test]'` 成功。README 使用标准隔离构建。
- 保留 1 条上游警告：Starlette 提示 TestClient 的 httpx 兼容路径将弃用。当前测试通过；后续升级测试传输时处理，不将警告隐藏为零。

## GitHub CI 补充

首次远程运行的 Linux/Windows 后端均通过，但浏览器 5 passed / 1 failed：

保留[失败运行及 trace 工件](https://github.com/loyce-cheng/worldmind/actions/runs/39526894775)。
界面现在显式显示“已暂停”；测试等待服务确认后的状态，再继续断言 700 ms 内 tick/资源不变，
并人为延迟真实暂停响应 500 ms 覆盖此时序，不更改业务响应、不删除稳定性检查、不开重试。
同代码的另一次远程运行通过，说明该断言受异步时序影响；仍保留并修复问题。
修复后本地重新运行格式、类型、构建和 6 项端到端测试均通过，无重试；
修复后的远程结果见 PR Checks，机器可读摘要保留两次远程运行链接。
