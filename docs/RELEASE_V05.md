# IntentWeave · 意织 0.5.0

可观察、可干预、可回放的 NPC 规划与协作实验台。

- 医生与快递员独立规划，通过有期限的工作单运输、交接和使用材料。
- 支持断路、资源竞争、取消与中断，提供 Full / Local 对照与逐步回放。
- 浏览器、Python SDK、CLI 与持久存档形成完整本地体验。
- 新名称与 intentweave 命令统一对外入口，旧 worldmind 接口、配置和录制继续兼容。
- 合并重复回放和场景调度，修复无效新配置导致原会话丢失，以及恢复后配置显示不一致的问题。

安装与体验见 [README](../README.md)。当前限定两个规划角色、一名规则竞争者和一张工作单；协作使用离线策略，无需 API Key。

验证：368 项后端测试通过；前端格式、类型与生产构建通过。浏览器验收由发布 PR 的 CI 检查。
