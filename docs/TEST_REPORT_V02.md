## 新增验收重点

- 后缀入口约束支持补丁先获取资源；约束不把未知当真，不刷新 TTL，不以局部通过代替全计划验证。
- 拼接后最多 30 动作；失败尝试和回退共享预算，空后缀不重复执行一次 Full。
- SQLite 重启读取、独立凭据、错误凭据/不存在/过期统一拒绝；名称和载荷边界、并发配额、损坏行、实际字节额度与异常时钟。
- 创建/读取均按记录版本完整重执行；恢复原完整记录并进入只读模式，失败不替换当前模拟。
- 服务端只保存存档凭据哈希；浏览器保存访问入口，不保存模型演示口令；名称 HTML 转义。
- 多次取消仍等待工作线程结束才释放写锁；错误线程结果被消费；非 ASCII 凭据返回拒绝而不是 500。
- SDK 显式命令 ID/版本支持幂等重试，409 不自动重发；不跟随重定向，不记录密钥或原始传输错误，沿用环境代理。
- 前端通过会话身份、操作代次和 revision 拒绝旧结果；替换会话后的迟到轮询不能覆盖新状态。
- 0.1/0.2 协议显式分派；把旧记录版本标签改成新版本不能冒充迁移，未知版本被拒绝。

## 失败记录与修正

- 初次存档测试有 3 项失败：Pydantic 插入空字段导致导出不等价、字节数变化。改为与导出一致的规范化序列化，保留原断言。
- 前端第一次类型检查发现 NodeList 依赖 DOM.Iterable；改用 `Array.from`，没有放宽 TypeScript 配置。
- 独立审查复现双重取消提前释放写锁，增加重复 shield 等待和线程回归测试；异常凭据比较改用字节。
- 审查发现 SDK 手动 transport 影响环境代理，恢复默认传输并验证代理/无重试行为。
- 两次使用额度限制使自动审批无法执行命令。未计作测试通过；恢复后重新运行完整后端验证。
- 原 0.1 暂停时序失败与 trace 保留在历史报告，本轮未删除相关浏览器断言。

## 尚未验证与边界

没有真实供应商调用、付费部署、公开 HTTPS、长期压力、多进程协调或独立研究基准。
供应商仍为协议模拟；持久回放不是运行会话自动续跑，模型等待与费用过程不进入剧情回放。
默认存档 7 天、64 份、64 MiB 有效载荷，每份 2 MB；SQLite 索引和空闲页不计入载荷额度。
存档不是静态加密或签名系统，不能抵御可改写数据库的管理员；浏览器清理后没有访问凭据找回。
当前兼容只覆盖明确支持的两个记录协议；未来动作语义变化需要新的分派与回归，不能只改版本号。
