## 版本与兼容

Python 包、前端包及锁文件、API 健康检查、目录和 OpenAPI 的应用版本统一为 **0.3.0**，浏览器显示 `v0.3.0`。升级后重新安装 Python 包并构建前端，避免继续加载旧安装元数据或页面。

本版整合上轮代码精简与资源生命周期修复，并整理测试、打包和说明文档；动作、规划顺序和预算语义没有变化。因此新录制继续使用 **`worldmind-0.2.1/river-1`**，支持 0.1、0.2、0.2.1 三种录制协议。旧存档不改标签、不重算历史哈希，也不需要迁移数据库。默认仍禁用模型调用。

## 仓库清洁度

检查 Git 实际跟踪的文件后，发现 **0 个**误提交的虚拟环境、依赖目录、Python 字节码、测试缓存、构建产物或 SQLite 数据库。工作区的 `.venv/` 和 `web/node_modules/` 各约 74 MB，是本地安装依赖，已有忽略规则，不随 Git 克隆或提交传播；保留它们可继续运行和验证项目。

- 补齐 `venv/`、`env/`、`build/`、`dist/`、工具缓存和覆盖率文件的忽略规则。
- wheel 与源码分发包只携带 Python 运行包及安装元数据，不夹带环境、网页依赖、运行数据库或测试。此前源码包自动携带测试，却缺少测试依赖的历史录制；现在用 `MANIFEST.in` 排除这部分不完整内容。完整测试、前端和研究证据仍由 Git 源码提供，浏览器演示应从源码安装。
- 后端测试显式使用 `tmp_path` 数据库；浏览器测试通过独立临时目录启动服务，并配置正常关闭，避免使用用户的 `var/` 账本或存档。
- 三个历史评测脚本默认把新输出写入 `var/benchmarks/v0.1`、`v0.2`、`v0.2.1`，支持 `--output`。历史 `docs/evidence/` 文件不再是默认写入目标。
- CI 在验证后检查已跟踪文件没有变化；前端构建已含 TypeScript 检查，移除重复调用并补充格式检查。

`var/` 可能包含用户数据，不能作为普通缓存删除。历史录制和对照目录保留原路径，使旧报告链接及原始实验仍可核对；测试执行层负责去重。根目录构思汇编与 `docs/plan/` 是有意保留的归档阅读形式，文档索引明确标为历史设想，不当作当前能力说明。
